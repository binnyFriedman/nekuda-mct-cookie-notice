A simple cookie consent banner with customizable text and colors.

== Description ==

Lightweight cookie notice banner for MCT websites. Customize all text and colors via Settings → Cookie Notice.

**Features:**
* Customizable message, link, and button text
* Full color customization
* Responsive & RTL-ready
* 365-day consent cookie

== Installation ==

1. Upload to `/wp-content/plugins/`
2. Activate the plugin
3. Configure at Settings → Cookie Notice
